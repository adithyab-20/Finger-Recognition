# Finger Recognition

> A CNN-based image classifier that recognizes hand gestures showing 0, 1, or 5 fingers.

## Features

* Classifies hand gestures into 3 categories (0, 1, or 5 fingers)
* Built with TensorFlow/Keras using Convolutional Neural Networks
* Trained on 9,000 images with 1,800 validation images
* Achieves ~96% accuracy on validation data

## Installation and Usage

```bash
# Clone the repo
git clone https://github.com/adithyab-20/Finger-Recognition.git
cd Finger-Recognition

pip install tensorflow keras matplotlib kaggle
```

## Dataset

Uses the [Fingers dataset](https://www.kaggle.com/datasets/koryakinp/fingers) from Kaggle containing hand gesture images.
